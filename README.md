Tipos de Commits
Os tipos mais comuns usados neste projeto são:

- feat: Introdução de uma nova funcionalidade (feature).
- fix: Correção de bugs.
- docs: Alterações na documentação.
- style: Alterações que não afetam o significado do código (ex: formatação).
- refactor: Mudanças que não corrigem bugs nem adicionam funcionalidades (ex: refatoração de código).
- perf: Melhorias de desempenho.
- test: Adição ou modificação de testes.
- chore: Tarefas auxiliares (ex: mudanças em scripts de build ou configurações).
